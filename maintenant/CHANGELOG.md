# Changelog

All notable changes to Maintenant are documented in this file.

## [Unreleased]

### Changed

- Remove the redundant Maintenant workspace heading beneath the login logo.
- Reposition the white logo gradient behind the gear-and-wrench icon.
- Remove the extra inner border from the circular logo badge.
- Remove the strong elliptical reflection from the circular logo badge.
- Give the circular logo backdrop a glossy badge finish with a luminous rim,
  curved highlight, and subtle depth.
- Reduce the circular logo gradient diameter by half.
- Make the logo backdrop a true circular radial gradient centered behind the
  logo.
- Add a centered white radial gradient behind the transparent logo on every
  page.
- Increase the standardized logo display size by 50%.
- Standardize the logo to the same display size on every page.
- Increase the displayed logo size across the login and application header.
- Remove the white logo container so the transparent logo sits directly on the
  app gradient.
- Update the app gradients and accents to match the logo palette of navy blue,
  white, and orange.
- Refresh the interface with a futuristic dark-blue-to-white gradient shell,
  glassy rounded panels, pill controls, and cleaner logo presentation.
- Allow local development login with any email and password when Supabase
  environment variables are not configured.
- Align the dark interface with the supplied Maintenant logo using deep navy
  surfaces, blue primary actions, orange attention accents, and larger logo
  treatments in the login and application header.

### Added

- Add a shared animated shine, glow pulse, and staggered sparkles to the logo
  badge on every page, with reduced-motion support.
- Add the initial responsive React application with Supabase authentication,
  protected maintenance routes, location navigation, and placeholder Historic
  Data and Process Facility views.
- Add Pump House 1 PT1 and FM1 numeric readings with authenticated Supabase
  persistence and accessible save feedback.
- Add the supplied Maintenant logo across login, application header, and
  browser favicon placements.
- Add the Supabase schema and RLS policies, environment template, Vercel SPA
  configuration, and complete setup and deployment guide.
