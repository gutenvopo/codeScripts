# Changelog

All notable changes to Youtube Playlist Observer should be documented in this file.

## v2.00 - 2026-06-02

- Added v2.00 script copy.
- Updated the v2.00 window title and script header to show the correct version.
- Restyled the v2.00 GUI with a futuristic dark-mode interface.
- Added a custom dark title bar and neon outer app border for the v2.00 window.
- Moved the project files into the `Youtube Playlist Observer` folder.
- Added project README and changelog files.
- Adjusted the helper Python environment path after moving the scripts into a subfolder.

## v1.00 - Initial Version

- Added Tkinter GUI for exporting YouTube playlist entries to Markdown.
- Added support for all positions, individual positions, ranges, and mixed selections.
- Added optional cookies file selection for restricted playlists.
- Added `yt-dlp` metadata loading without downloading playlist videos.
